# Perennius releases

Downloads for [Perennius](https://perennius.ai), the academic workspace.

Get the latest version from [Releases](https://github.com/thomasbierly/perennius-releases/releases/latest):

- **Linux:** the AppImage (updates itself), a .deb for Debian and Ubuntu, an .rpm for Fedora and openSUSE, or the PKGBUILD for Arch (`makepkg -si`).
- **macOS and Windows:** coming once their signing is set up.

This repository holds only the release files and the update manifest (`latest.json`) that copies of Perennius check, when asked, for signed updates. The source isn't here.
